Messages are per store. You see the stores you have access to, and the store
selector is the same one the dashboard uses — change it in either place and both
follow.

## Who sees a message

A message belongs to a store, not to a person. Everyone with access to that
store sees it, including people who were not on shift when it was posted. There
is no private or direct message.

**Every message shows the name of whoever posted it**, and the text is whatever
they typed.

## Pinned messages

A message can be pinned until a date. Pinned messages stay at the top until that
date passes, then fall back into the ordinary run.

## What a message is

A message is a note on a store's noticeboard. It is posted, everyone with access
to that store can see it, and nothing records who has read it or whether anyone
has. There is no acknowledgment, no completion and no per-person state — a
message is the same object for everyone who opens the page.
