## What N-3 delivers

1. **Publish settings (org-level, ADMIN)** at `/nutrition/publish`:
   - **Public menu on/off** — **off by default**; nothing is public until an
     ADMIN turns it on.
   - **Web address slug** (e.g. `keva-juice`), unique across orgs, editable.
   - **Included menu groups** — ADMIN picks which Square menu groups appear
     (lean default: none ticked; a suggested set excludes names like
     Archived, Retail, Shirts, Bouquets, Services, Fundraising).
   - **Hide individual items.**
   - **Disclaimer text** with a sensible default (see 5).
   - Shows a live count: "N items will show nutrition · M will show 'coming
     soon' · K hidden".
2. **Public menu page** `/menu/[slug]` — no login, read-only:
   - items grouped by menu group; each item with its sizes;
   - **calories per size on the list** (whole item as sold — what menu boards
     use) for Verified items;
   - tap an item → the full N-2 Nutrition Facts label (same component, same
     rounding, same serving settings) and the "Contains:" line;
   - **allergen filter** ("hide items containing …") and search, client-side;
   - unverified items per N3-F1.
3. **Embed:** an iframe snippet shown on the publish page
   (`<iframe src="…/menu/[slug]?embed=1" …>`), the embed view without page
   chrome, and an auto-height script snippet (postMessage) if cheap. Set
   `Content-Security-Policy: frame-ancestors *` (or an allowed-origins list —
   N3-F5) **only** on `/menu/*`; every other route keeps its current framing
   protection.
4. **Data the public page may expose — and nothing else:** item display name,
   size names, menu group names, computed rounded label values for Verified
   items, allergen labels, the disclaimer, the org's display name. **Never**:
   prices or costs, ingredient names or amounts, recipes, vendor data, label
   documents or source links, user names, internal ids beyond what the URL
   needs. A dedicated serializer builds the public payload; the page never
   receives app-side objects.
5. **Honesty and safety copy:**
   - default disclaimer: values are for standard recipes; customizations,
     add-ons and substitutions change nutrition;
   - **cross-contact notice:** drinks are blended on shared equipment, so
     items may contain traces of allergens not listed (lean: always shown on
     allergen views — N3-F4);
   - "Last updated" date (most recent verification among shown items).
6. **Performance & abuse:** cache the public payload per org (revalidate on a
   short interval and on publish-setting changes); no per-request recompute of
   ~450 recipes; basic rate limiting or reliance on caching — audit decides.
   Unknown slug or menu turned off → a plain 404 (no hint that the org
   exists).
7. **Promotion stamp for `8c94126`** (N-2) in the docs commit: 2026-11-02,
   `--no-ff`, main `22b8a7f..8c94126`, staging fast-forwarded, migration
   `20261102230000_n2_nutrition_serving_settings`. Staging evidence: Liquid
