## What N-1 delivers

1. **Ingredient nutrition.** Each ingredient can carry one nutrition record:
   values *per a stated amount* in a unit of the ingredient's own dimension
   (e.g. "per 1 fl. oz", "per 28 g", "per 1 each"), so the math rides the
   same unit conversion recipes already use for cost. Nutrients — the FDA
   Nutrition Facts set: calories, total fat, saturated fat, trans fat,
   cholesterol (mg), sodium (mg), total carbohydrate, dietary fiber, total
   sugars, added sugars, protein, vitamin D (mcg), calcium (mg), iron (mg),
   potassium (mg). Every nutrient nullable (unknown ≠ zero). A source note
   (free text: "label", "USDA FDC #…", "supplier spec").
2. **Allergens.** Per ingredient, the FDA major nine: milk, eggs, fish,
   crustacean shellfish, tree nuts, peanuts, wheat, soybeans, sesame.
   "Contains" only in N-1.
3. **Not-food flag.** Cups, lids, straws, napkins, cleaning supplies carry no
   nutrition and must not make a recipe "incomplete". A per-ingredient flag,
   settable in bulk.
4. **Nutrition CSV import** (ADMIN), following the IV-3 ingredient import
   pattern: match rows to existing ingredients by name (brand + " " + name or
   name, whitespace/case-folded, as BEV-1 F5), preview with per-row status,
   then apply. Never creates ingredients. This is what makes entering ~120
   food ingredients practical — planning chat will prepare the file.
5. **Computed nutrition engine** — `src/lib/recipe-nutrition.ts`, mirroring
   `src/lib/recipe-cost.ts`: walks recipe lines and sub-recipes (yield
   division, unit conversion via the existing units code), sums nutrients,
   unions allergens, and returns completeness: which lines lack nutrition
   (not-food lines excluded) and a complete/incomplete verdict. A nutrient is
   only summed as a number if every contributing food line has it; otherwise
   that nutrient is reported as incomplete, never silently under-counted
   (same principle as F5).
6. **Menu nutrition page** — a read view listing sales items with recipes:
   calories, a few key nutrients, allergens, completeness ("11 of 12
   ingredients"), filter to incomplete, and the list of ingredients blocking
   completeness ranked by how many items each blocks (the BEV-1 "To fix"
   pattern). Clicking an item shows its full computed breakdown. No label
   formatting or FDA rounding — that is N-2.
7. **Ingredient page**: a nutrition + allergens + not-food section on the
   ingredient edit view.

Out of scope: FDA rounding/label layout (N-2), public pages (N-3), exports
(N-4), modifiers (N-5), any write to Square, any change to cost math.
