## 1 · What this is

A training lesson gets one external link with its own label — "Set up your
Square account" → `squareup.com`, "Download the Homebase app" → an app store.

The case: Day 1 needs to send a new hire to squareup.com. The only field that
took a URL was **Video URL**, so the trainee is shown a **Watch video** button
pointing at Square's homepage. It works and it tells them the wrong thing.

This is deliberately **not** the HR-32 shape. HR-32 links a *document* — a thing
with instructions, an audience, and a place in the library. This links a
*destination*, which is not a document and must never be forced into the
Document Library to become linkable.

After this row a lesson can carry all three independently: a video, an external
destination, and a linked document.

## 5 · Build (after approval)

**5a · Schema.** Two nullable columns on `TrainingLesson`:
`externalLinkUrl String?`, `externalLinkLabel String?`. Hand-authored migration
per `docs/MIGRATIONS.md` (`migrate dev` broken, P3018). Additive: no backfill, no
drop, every existing row valid with NULL.

Apply to dev and verify with the branch literal and `ep-` host **in the same
output as the row** — `br-broad-wave`.

**5b · Validation — this is the one thing to get right.**

`videoUrl` takes any string and drops it into an `href`. That is a known,
accepted COMMENT. **Do not reproduce it here.** The new URL must:

- parse as a URL
- be `http:` or `https:` — nothing else reaches an `href`
- 400 on anything else, on **both** write paths

Empty/absent stays valid; the field is optional.

**Label:** optional. When absent, fall back to the hostname via
`externalUrlHost`, the same way HR-32's block does. A URL with no label is
still usable; a label with no URL is a no-op and should be stored as NULL rather
than rejected.

Fire the validator against real rows before committing — and check the
**positive** case passes, not only that the negatives fail. A validator that
refuses everything passes every negative test. HR-32 caught two false-green
probes this way; the same discipline applies.

**5c · Renderer.** Its own button in `training-module-view.tsx`, beside Watch
video, using the label (or hostname fallback). `target="_blank"`,
`rel="noopener noreferrer"` — **both tokens**; there are already two anchors in
this file carrying a bare `noopener`, filed as a COMMENT, which is the reason to
be explicit here.

Renders in every mode for every role. No gate. See §2.

**5d · Both forms.** A URL input and a label input, under Video URL and above
Linked document. Same field pair in Edit Lesson and New Lesson. Duplicate carries
them.

**5e · Export.** Both fields in the JSON export, plain. The CSV round trip still
drops them — say so in the route comment, as HR-32 did for its own field.

**5f · Roadmap + DEPLOY_LOG.** `cp docs/ROADMAP.yaml docs/ROADMAP.yaml.bak`
first; edit by line number, higher line first; prove with
`diff docs/ROADMAP.yaml.bak docs/ROADMAP.yaml | grep -c "^<"` returning 0 with no
error line above it. Parse the file as YAML afterwards — a malformed row breaks
`/internal/roadmap` silently.

Row notes carry: why this is not the HR-32 shape (destination, not document);
that the URL is validated and `videoUrl` still is not; and that there is
deliberately no role gate.
