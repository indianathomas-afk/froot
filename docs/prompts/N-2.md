## What N-2 delivers

1. **Serving settings (org-level, ADMIN):**
   - **Drink serving size** — default **12 fl oz**, editable (e.g. 8, 12, 16).
   - **Size table** — what each Square size name means in volume, e.g.
     Kids = 12 fl oz, S = 20, M = 24, L = 32 (read the real variation names
     Keva uses from synced sales items; the ADMIN fills the volumes).
   - Items whose size isn't in the table (bowls, cookies, pretzels, retail)
     are labeled **per item**: 1 serving = the whole item.
2. **Per-item override (ADMIN):** an item can set its own volume and/or its own
   serving size, beating the size table/default.
3. **The math:** servings per container = item volume ÷ serving size.
   Per-serving values = the recipe's computed totals ÷ servings per container.
   Rounding of "servings per container" per FDA (whole numbers, but "about"
   with nearest 0.5 between 2 and 5 — audit confirms from 21 CFR 101.9(b)).
4. **The label:** FDA format, rendered in-app:
   - serving size line ("Serving size 12 fl oz (355 mL)") and servings per
     container ("2 servings per container", "about 2.5 servings per
     container");
   - **dual columns: per serving and per container** whenever there is more
     than one serving (lean — Gary rules; see F2);
   - FDA rounding rules for every nutrient and calories, and %DV from FDA Daily
     Values (the same DV table N-1c uses), from 21 CFR 101.9(c) — cite it;
   - "Contains:" allergen line from the union of ingredient allergens.
5. **Honesty states on the label:**
   - any **missing** nutrient (incomplete) shows as "—" with a note — never
     rounded to 0;
   - an item that isn't fully **Verified** shows a clear "Estimated — not for
     publication" banner (N-3 will only publish Verified).
6. **Where it lives:** a label preview for each item (from `/nutrition/menu`,
   click an item → "Label"), with a serving-size picker on the preview so the
   ADMIN can see the label at another serving size before changing the
   setting. Print-friendly view (browser print). Image/PDF export is N-4.
7. **Promotion stamp for `22b8a7f`** (N-1d) in the docs commit: 2026-11-02,
   `--no-ff`, main `560f350..22b8a7f`, staging fast-forwarded; migration
